# Agent 学习路线

在校大学生转智能体工程师（AI Agent 方向）的系统学习项目，**目标入职 DeepSeek Agent 方向**。

## 文档

- `学习规划.md` — **主规划**：三阶段路线（认知构建→深耕作品→投递冲刺）+ 14 课课程表
- `30天冲刺计划.md` — 阶段Ⅰ执行细则（14 课 + 概念测验 + 最小 demo 验收）
- `DeepSeek求职情报.md` — 目标岗位/JD 提炼/投递渠道/能力差距清单（2026-08-12 核实）

## 核心策略

- 目标：**DeepSeek Agent 方向**（主攻：通用 Agent 数据产品经理；备选：Harness 团队 / AI 跨界 / 测试开发）
- 路径：实习优先（DeepSeek 全岗位接受实习）
- 模式：课程制（我讲课你听课，练习按需触发）+ 最低限度实践（阶段 demo + 毕业项目）
- 前沿：每课"前沿 5 分钟"（harness / agentic RL / 评测 benchmark），跟上 AI 发展节奏
- 已有基础：MCP 配置 / opencode 插件 / 向量知识库规划，直接转化为实战项目
