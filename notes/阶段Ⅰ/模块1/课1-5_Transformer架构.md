# 课 1-5：Transformer 架构（编码器 / 解码器 / 位置编码）

> 模块 1：DL 理论底座 ｜ 教材：UDL ch.12.4-12.8（Transformers / NLP / BERT / GPT3 / 机器翻译）
> 状态：✅ 讲义已生成（2026-08-14），章节号按 MIT Press 官方目录核实

## 教学目标
1. 掌握 Transformer 块 = 多头注意力 + 残差 + LayerNorm + FFN
2. 区分编码器（双向理解）与解码器（单向生成）
3. 理解位置编码的必要性，认识 GPT 系列的"解码器-only"路线

## 知识点详解

### 1. Transformer 块（重复的积木）
```
x → 多头自注意力 → 残差连接 + LayerNorm → FFN(两层MLP) → 残差 + LayerNorm → 输出
```
- 残差连接：x + F(x)，给梯度一条"高速公路"（对抗梯度消失）
- LayerNorm：稳定每层数值分布
- FFN：每个位置独立过两层 MLP（注意力负责"交流"，FFN 负责"消化"）
- 类比：开会（注意力=彼此交流）→ 各自写纪要（FFN=独立思考）

### 2. 编码器 vs 解码器
| | 编码器 | 解码器 |
|---|---|---|
| 代表 | BERT | GPT 系列 |
| 注意力 | 双向（看上下文） | 单向掩码（只看左边已生成的） |
| 用途 | 理解任务（分类/检索） | 生成任务（逐 token 续写） |

### 3. 位置编码
- 注意力本身对顺序不敏感 → 必须注入位置信息
- 方案：正弦位置编码（UDL 12.4.3）/ 可学习位置嵌入（GPT 用）/ RoPE 旋转位置编码（**DeepSeek-V3/R1 与多数 2026 主流模型使用**）

### 4. GPT 路线：解码器-only
- 去掉编码器，只保留"预测下一个 token"的生成能力
- 训练任务简单纯粹 → 规模放大奏效 → 这就是今天所有 LLM 的架构祖宗（UDL 12.7 以 GPT3 为例）
- 预训练好的解码器再对齐（SFT/RLHF，课 1-6）

## 记忆点
1. 块结构：注意力（交流）+ 残差/归一化（稳定）+ FFN（消化）
2. 编码器=理解（双向）、解码器=生成（单向）
3. 位置编码三选一：正弦 / 可学习 / RoPE（DeepSeek 路线）

## 面试话术
