# 课 1-2：损失函数与训练目标

> 模块 1：DL 理论底座 ｜ 教材：UDL ch.5（Loss Functions）
> 状态：✅ 讲义已生成（2026-08-14），章节号按 MIT Press 官方目录核实

## 教学目标
1. 理解损失函数 = "模型输出与正确答案的差距度量"
2. 区分回归用 MSE、分类用交叉熵，以及两者行为差异
3. 建立"训练 = 最小化损失"的心智模型

## 知识点详解

### 1. 为什么需要损失函数
- 监督学习：输入 x、真实答案 y，模型输出 f(x,θ)
- 损失 L(y, f(x,θ)) 衡量"差多远"；训练目标 = 找 θ 使平均损失最小
- 类比：考试评分规则——规则不同（MSE/交叉熵），优化的行为就不同

### 2. MSE（均方误差）：回归任务
```
L = (1/N) Σ (yᵢ - f(xᵢ))²
```
- 惩罚与误差的平方成正比：差 2 分罚 4，差 10 分罚 100 → 对离群值敏感

### 3. 交叉熵（Cross-entropy）：分类任务
```
L = -Σ yᵢ log(f(x)ᵢ)     （y 为 one-hot 真实标签）
```
- 预测概率越接近 1（正确类），损失越小；错误自信（0.99 给错类）惩罚极重
- **LLM 的预训练损失就是交叉熵**：预测"下一个 token"是词表上的分类任务
- softmax + 交叉熵是标准搭配

### 4. 两种损失的直觉区别
| | 适合 | 对"错得很离谱"的态度 |
|---|---|---|
| MSE | 回归（预测连续值） | 平方爆炸惩罚 |
| 交叉熵 | 分类（概率分布） | 对数惩罚，温和但有梯度下限 |

## 公式推导（跟练）
- 二分类交叉熵展开：L = -(y log p + (1-y) log(1-p))
- 验证：y=1、p→1 时 L→0；p→0 时 L→+∞

## 记忆点
1. 损失 = 差距度量；训练 = 最小化平均损失
2. 回归 MSE、分类交叉熵；LLM 预训练用交叉熵
3. 交叉熵对"自信的错误"惩罚最重——与 LLM 幻觉直接相关

## 面试话术
> "LLM 的训练目标就是下一个 token 的交叉熵最小化——所以模型本质上是被训练成'最可能接下去的词'，这也是它需要 RLHF 对齐的原因之一。"
