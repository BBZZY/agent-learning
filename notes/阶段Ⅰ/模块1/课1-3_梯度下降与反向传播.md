## 教学目标
1. 理解梯度 = 损失增长最快的方向；梯度下降 = 反方向小步走
2. 掌握学习率 η 的作用与选择直觉
3. 理解反向传播 = 链式法则自动求梯度（会推两层例子）

## 知识点详解

### 1. 梯度下降（Gradient Descent）
```
θ ← θ - η · ∂L/∂θ
```
- ∂L/∂θ 是梯度：损失对每个参数的变化率
- η（学习率）：每步走多大。太大 → 震荡/发散；太小 → 太慢
- 类比：摸黑下山——每一步感受脚下坡度，朝最陡的下坡方向走一小步

### 2. 随机梯度下降（SGD）
- 全量数据算梯度太贵 → 每次随机取一小批（mini-batch）估计梯度
- LLM 训练 = 大规模 SGD 的工程化（配合 Adam 等自适应优化器）

### 3. 反向传播（Backpropagation）= 链式法则
两层网络（x → h → y），损失 L 对 w₁ 的梯度：
```
∂L/∂w₁ = ∂L/∂y · ∂y/∂h · ∂h/∂w₁
```
- 从输出层往回逐层传播误差信号
- 类比：接力赛传话——最后一棒知道最终差多少，把"责任"按贡献往回分

### 4. 为什么能训练任意深的网络
- 链式法则可无限连乘 → 深度可微模型都能用同一套算法训练
- 副产物：梯度消失/爆炸（连乘项 <1 或 >1）→ 残差连接/归一化的由来（课 1-5）

## 公式推导（跟练，本课核心）
1. 单神经元：y = w·x + b，L = ½(y - t)² → ∂L/∂w = (y-t)·x
2. 验证直觉：误差 (y-t) 越大、输入 x 越大 → 梯度越大 → 参数更新越多
3. 两层 MLP 的链式展开（写出三项连乘）

## 记忆点
1. 梯度下降三要素：梯度方向、学习率、批量大小
2. 反向传播 = 链式法则；误差按贡献往回分配
3. 梯度消失/爆炸 → 深层网络训练难 → 残差连接的动机
