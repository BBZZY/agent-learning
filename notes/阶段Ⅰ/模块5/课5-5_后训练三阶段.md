# 课 5-5：模型后训练①——预训练 / SFT / RL 三阶段全景

> 模块 5：工程化+求职 ｜ 教材：ai-agent-book ch7「模型后训练」前半
> 状态：✅ 讲义已生成（2026-08-14），内容基于本地 clone 教材原文逐节提取

## 教学目标
1. 掌握三阶段全景（预训练/SFT/RL）与"先形后神"判据
2. 理解 SFT 与 RL 的本质区别（mass-covering vs mode-seeking）
3. 掌握 LoRA 与 SFT 数据合成流水线

## 知识点详解

### 1. 三阶段全景
| 阶段 | 做什么 | 成本 | 类比 |
|---|---|---|---|
| 预训练 | 海量文本"预测下一个词"（NTP），学会语言/知识/推理 | 最贵（百万~千万美元） | 读万卷书 |
| SFT | 几千~几万条"问题—标准回答"示范对，教会格式/风格/流程 | 便宜快稳 | 老师手把手教 |
| RL | 模型试错，按奖励调整行为概率 | SFT 的几十~上百倍 | 自己下场做题打磨 |

- 核心认知：模型的输出本质是概率分布，训练归根结底是调整这个分布——三阶段区别只在"想要什么、用什么信号定义想要"
- **SFT 与预训练是同一个任务**（都预测下一个词）：差别只在于数据（示范对 vs 原始文本）与**loss masking**（损失只算在回答上，`-100` 屏蔽 prompt token）
- SFT 固化的是**协议性知识**（怎么说、怎么做），不是事实性知识（靠预训练或 RAG）

### 2. "先形后神"：何时先 SFT 再 RL
- 判据：RL 的奖励函数必须先能把输出"解析出来"——结构化输出不稳定时，SFT 先把"形"（格式）立住，RL 再求"神"（策略）
- 但"必须 SFT"仅在"较小基模 + 严格结构化输出"下成立：**DeepSeek-R1-Zero 证明强基模可直接 RL**，但仍加回"冷启动 SFT"把形立稳（输出可读性差、中英混杂）
- 本质区别：SFT 最大化标注答案概率（**mass-covering** 覆盖多个模式）；RL 最大化期望奖励（**mode-seeking** 集中到高奖励峰）
- RL 在线反馈三个机会：可评估示范之外的候选 / 利用"验证比生成容易"的任务（RLVR 优势）/ 在策略实际访问的状态上训练（避免协变量漂移）

### 3. LoRA（低秩适配）
- 只挂 1%-5% 参数的小补丁，冻结原权重，遗忘风险低
- 要点：覆盖所有主要权重矩阵（尤其 MLP 层）；学习率约为全参微调 10 倍；SFT 用 rank 64-256，RL 用小 rank（8-32）

### 4. SFT 数据三条来源与合成流水线
- 三条来源：人工专家示范（质量天花板，作种子）/ 教师模型生成（合成数据）/ 拒绝采样（自己采样多候选、验证器筛正确样本）
- "与其堆十万条脏数据，不如精修一万条干净数据"
- **数据合成流水线**：线上数据 → 任务蓝图 → 合成任务 → 多次候选轨迹 → 任务验证与轨迹验证 → SFT 数据
  - 任务验证（可完成性、难度、参考正确性）与轨迹验证（最终状态、工具调用、业务约束）分开
  - 失败轨迹不直接当示范，可构造 DPO 偏好对或发现覆盖缺口
- 蒸馏两条路线：Prompt 蒸馏（"长提示+思考型教师"压缩为"短提示+非思考学生"，20-30 倍提速）与 CoT 蒸馏（教师思考轨迹转给学生，可恢复 70%-80% 能力，DeepSeek-R1 蒸馏为代表）
- 实验揭示（书中）：SFT 只是**激活了预训练已有的能力**（训练数据无中文，SFT 后能零样本中文思考——不是 SFT 自身的泛化）；记新知识靠**继续预训练**而非 SFT

### 5. 何时 SFT、何时 RL（决策顺序）
1. 先问需要后训练吗（多数问题 Harness 工程可解决）
2. 需要就先试 SFT（格式/协议固化；不适合注入事实）
3. SFT 不够再加 RL（需泛化新场景、探索最优策略、标注成本过高）
- 代价：SFT 样本效率高但泛化受数据覆盖限制；RL 可探索示范外策略但样本效率低、不稳定

## 记忆点
1. 三阶段：预训练给知识、SFT 给协议、RL 给策略；SFT 与预训练同任务（loss masking）
2. 先形后神：SFT 立格式、RL 求策略；mass-covering vs mode-seeking
3. 决策顺序：Harness 先行 → SFT → RL；LoRA rank 64-256（SFT）/ 8-32（RL）

## 面试话术
> "后训练的决策顺序是 Harness 先行、SFT 立形、RL 求神。关键判断是'能力能否被外部规则表达'——不能表达的高维能力才需要后训练，且 SFT 不负责注入事实（那是预训练和 RAG 的事）。"
